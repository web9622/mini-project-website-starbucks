# ☕ 스타벅스 웹사이트 미니 프로젝트

## 📝 프로젝트 개요 (Overview)

이 프로젝트는 HTML, CSS, JavaScript와 같은 웹 기본 기술을 활용하여 스타벅스(Starbucks) 웹사이트의 반응형 랜딩 페이지(Landing Page)를 클론 코딩한 미니 프로젝트입니다. 웹 표준 및 최신 웹 디자인 트렌드에 맞춰 사용자에게 매력적이고 인터랙티브한 경험을 제공하는 것을 목표로 합니다.

## ✨ 주요 기능 (Features)

  * **반응형 디자인:** PC, 태블릿, 모바일을 포함한 다양한 디바이스 환경에서 최적화된 레이아웃을 제공합니다.
  * **메인 랜딩 페이지 구현:** 스타벅스 브랜드의 핵심 이미지를 보여주는 홈 화면을 구현합니다.
  * **내비게이션 메뉴:** 상단 고정 또는 스크롤 시 변화하는 내비게이션 바를 포함합니다.
  * **시각적 효과:** CSS 애니메이션이나 JavaScript를 활용한 인터랙티브한 요소를 포함할 수 있습니다.
  * **웹 표준 준수:** 시맨틱 $\text{HTML}$ 태그 사용 및 구조적 $\text{CSS}$ 설계를 통해 웹 접근성을 고려합니다.

## 💻 사용 기술 (Technologies)

이 프로젝트를 구축하는 데 사용된 주요 기술 스택은 다음과 같습니다.

| 분류 | 기술 | 설명 |
| :--- | :--- | :--- |
| **마크업 언어** | $\text{HTML5}$ | 웹 페이지의 구조와 콘텐츠를 정의합니다. |
| **스타일링** | $\text{CSS3}$ | 디자인, 레이아웃, 반응형 웹 구현 및 시각적 효과를 담당합니다. |
| **상호작용** | $\text{JavaScript}$ | 동적인 기능 및 사용자 상호작용(예: 메뉴 토글, 슬라이드 효과 등)을 구현합니다. |

## 🚀 설치 및 실행 (Installation & Usage)

로컬 환경에서 프로젝트를 실행하는 방법입니다.

### 1\. 저장소 클론

다음 명령어를 사용하여 이 저장소를 로컬 환경으로 복제합니다.

```bash
git clone https://github.com/web9622/mini-project-website-starbucks.git
```

### 2\. 파일 열기

프로젝트 폴더($\text{mini-project-website-starbucks}$)로 이동합니다.

```bash
cd mini-project-website-starbucks
```

루트 디렉토리에 있는 **`index.html`** 파일을 웹 브라우저(Chrome, Edge 등)로 직접 열어 실행합니다.
